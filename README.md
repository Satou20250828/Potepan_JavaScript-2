# 電卓アプリ（JavaScript）

## 概要
プログラミングスクールの実践課題として、  
JavaScriptのイベント処理と状態管理を学ぶ目的で作成した、  
ブラウザ上で動作する電卓アプリです。  
数字ボタンや演算子ボタンの入力に応じて、四則演算を行います。

## 作成した目的
本アプリは、JavaScriptを用いたイベント処理や状態管理の理解を目的として作成しました。  
特に、ボタン操作に応じて数値や演算子の状態を保持し、  
計算結果を画面に反映する一連の流れを学ぶことを意識しました。

## 使用技術
- HTML  
- CSS  
- JavaScript  

## 実装した機能
- 数字入力機能  
- 四則演算（加算・減算・乗算・除算）  
- 計算結果の表示  
- クリア機能  
- ボタンクリックによるイベント処理  

## 工夫した点
- 連続して演算子が押された場合でも、  
  計算が破綻しないよう入力制御を行いました。
- 入力中の数値と計算結果を分けて管理し、  
  状態が分かりやすくなるようにしました。
- シンプルで直感的に操作できるUIを意識しました。

## 苦労した点
電卓アプリを実装する中で、  
小数点を含む計算が正しく入力できない不具合が発生しました。  
具体的には「1.5 + 1.2」と入力しようとすると、  
「1.5 + 12」となってしまう問題がありました。

原因を調査したところ、  
小数点の入力可否を全体で一律に管理していたため、  
演算子入力後も「すでに小数点が入力済み」と判定されていたことが分かりました。

そこで、以下のように修正しました。

- 演算子が入力されたタイミングで、小数点の入力状態をリセットする  
- 「現在入力中の数値ごと」に小数点の入力可否を管理する  

その結果、演算子の前後それぞれで  
小数点を正しく入力できるようになりました。

この経験から、  
**UIを伴う処理では、状態を分けて管理することがバグ防止につながる**  
ということを学びました。

## 振り返り・今後の改善点
電卓アプリを通して、  
JavaScriptでのイベント処理や状態管理の理解が深まりました。  
今後は以下のような改善を行い、機能の拡張に挑戦したいと考えています。

- キーボード操作への対応  
- 計算履歴の表示  
- より複雑な計算への対応
